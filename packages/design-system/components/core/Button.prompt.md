Small, restrained UI button — the default click target across the workspace (composer send, panel actions, citation "Open document").

```jsx
<Button variant="primary" size="md">Ask</Button>
<Button variant="ghost" icon={<CopyIcon/>}>Copy</Button>
<Button variant="danger">Discard fact</Button>
```

Variants: `primary` (filled accent, main actions), `ghost` (neutral border, secondary), `outline` (accent border/text, tertiary), `danger` (contradict-red border, destructive). Sizes: `sm`, `md`, `lg`.
